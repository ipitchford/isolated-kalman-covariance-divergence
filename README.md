# Observable systems with divergent isolated Kalman covariances

**A counterexample to the isolated Kalman filtering convergence conjecture**

Author: Anonymous · Version 0.2.0-candidate, 4 November 2026 · Text CC0 1.0 · Code MIT (see `LICENSE.md`)

Status: unrefereed candidate. Prepared with AI assistance and checked internally. No human peer review; no proof is formally (machine) verified.

## In plain English

The *isolated Kalman filter* (IsoKF) lets robots or sensors in a network share an estimation task cheaply. When an observation involves a few nodes, only those nodes do a proper update. Their correlations with every other node are rescaled by a simple correction factor. Its authors (Jung, Luft and Weiss, *Autonomous Robots* 2025) conjectured that, whenever the system is observable and controllable, the covariance this filter reports always settles to one finite, stable steady state.

That conjecture is false.

- **A three-node counterexample (proved).** Three states are observed in pairs through sums x₁+x₂, x₂+x₃ and x₃+x₁. One epoch of these observations determines the whole state. Even so, the reported variances grow without limit. Every local matrix the filter uses stays valid, and the ordinary Kalman filter stays bounded.
- **Only unstable dynamics can do this, but only slightly unstable (computer-assisted proofs).** With stable dynamics the reported variances are always bounded. With dynamics that grow by as little as one part in 10⁸ per step, a large starting uncertainty is proved to diverge.
- **No steady covariance attracts every prior (computer-assisted proof).** At 5% variance growth per step, starting from the identity gives a bounded covariance, while starting from 10¹² × identity gives a divergent one.
- **What actually goes wrong (numerical finding).** In high-precision tests of the divergent cases, the *actual* error of the IsoKF estimate stays bounded. The reported covariance, however, becomes absurdly pessimistic, up to 10¹⁹⁰ times too large. The failure is that the filter's uncertainty stops meaning anything, not that the estimate runs away.
- **Where it is safe (proved).** Local matrices always stay valid exactly when observation groups share at most one node. Relative (difference) measurements with a directly observed anchor give bounded variances.

## Reproduce

From this folder (Python 3.10 or later, [uv](https://docs.astral.sh/uv/)). Every script needs `--out NEWDIR`, refuses to overwrite an existing directory, performs explicit checks that also work under `-O`, and exits nonzero on failure.

```sh
# exact rational checks (standard library only)
uv run python3 -I -B scripts/verify_pairwise_divergence.py --out /tmp/isokf_check/pairwise
uv run python3 -I -B scripts/verify_exact.py --out /tmp/isokf_check/exact
uv run python3 -I -B scripts/verify_anchored_identity.py --out /tmp/isokf_check/anchored
uv run python3 -I -B scripts/fingerprints.py --out /tmp/isokf_check/fingerprints
# interval certificates C1-C3 and numerical findings (mpmath 1.3.0; about 15 s in total)
sh scripts/run_ext.sh /tmp/isokf_check/ext ""        # or "-O"
# figures (matplotlib 3.10.8)
uv run --with matplotlib==3.10.8 python3 -I -B scripts/plot_growth.py --out /tmp/isokf_check/growth
uv run --with matplotlib==3.10.8 python3 -I -B scripts/plot_coexistence.py --out /tmp/isokf_check/coexistence
# paper
pdflatex -jobname=isokf_manuscript manuscript.tex && bibtex isokf_manuscript && pdflatex -jobname=isokf_manuscript manuscript.tex && pdflatex -jobname=isokf_manuscript manuscript.tex
# bibliography (uses saved records; fetches only records that are missing)
python3 -I tools/make_refs.py refs.bib tools/records
```

## Boundaries

- The object studied is the mathematical recurrence of the published update equations. The `ikf_lib` software was inspected at a pinned commit, but not compiled or run. No software failure is claimed.
- Theorems 6.2–6.4 are computer-assisted. Escape from large priors is certified for every a² in (1, 1.38]. Entry from an explicit prior is certified only at eight listed values of a². Nothing is proved for a² in (1.38, 2+√5).
- The bounded actual error and the divergence thresholds are numerical findings, not theorems. The deletion threshold is close to 2+√5 but has an unresolved finite-horizon bias.
- At a = 1, large priors are only shown to leave the certified regime; global boundedness there is not established.
- The results for Schur-stable dynamics concern boundedness only. Uniqueness of the steady state for stable dynamics remains open.
- The novelty statement rests on a bounded literature search. Luft et al. (2018, IJRR), the journal source of the correction factor, was read in full: it proves that two-robot blocks stay positive definite (credited at Theorem 8.1) but makes no claim about boundedness or convergence of the covariance and gives no divergence example.
